**Мой проект-бот с покемонами**
Основная задумка бота-игра в покемоны. Пока что игра состоит из нескольких команд: /go, /attack, /info, /feed.
*go* - создание покемона(изображение, имя, здоровье и атака)
*attack* - атакует покемона соперника(рабтавет только при ответе на сообщение)
*info* - выдает тебе всю информацию про твоег покемона
*feed* - комежка покемона, происходит раз в 20 секунд, иначе вылезает сообщене, что можно покормить только в какое-то время
